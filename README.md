# The ORB Skill

An interactive field guide to using ORB for education and self-improvement.

Open `index.html` directly or serve the directory with any static web server. The complete twenty-point guide is self-contained: no package installation, CDN, account or AI connection is needed for local navigation.

## What is included

- A gently rotating, keyboard-accessible globe and an equivalent reading list.
- A six-direction compass that distinguishes spatial relationships from workflow stages.
- Twenty readings, practical exercises and claim-specific evidence notes.
- In-page field notes, bookmarks and navigation history.
- JSON checkpoint export/import and copyable prompts for continuing in chat or Orbiverse.
- Print styles for the current reading, sources and field note.
- Guidance for Active Journey, Rest Journey and later video production. No generated narration or video is included.

Notes are held in the open page's memory. Export a checkpoint before closing or reloading; import restores this edition's saved place, notes, bookmarks and trail. This page does not transmit notes, generate AI responses, or create reminders.

The guide follows the installed ORB navigation and artifact instructions inspected September 7, 2026. Related public entry points can differ in edition. Learning-research references support individual techniques, not a claim that ORB as a complete system has been validated. Practical exercises are authored suggestions.

Part of the [ORB archive](https://visualizationcreation.github.io/orb-archive/).

## Publication

The root `index.html` and `.nojekyll` support static GitHub Pages publication. Metadata is in `orb-metadata.json`. Keep the published directory free of personal checkpoints and private field notes.
